# Project Title

## Project Description

## Intended User or Player
Individuals who are interested in purchasing space goods and items. 

## User or Player Goal
Users should be able to properly navigate and add items they wish to purchase as well as use the websites other features. 

## Main Features
Navigation bar, login button, cart button with displays your cart total in another page, clear cart button, theme toggle button, add to cart buttons, clickable header logo with redirects users back to featured home page.  

## JavaScript Features
Alert tells user when item is added to cart,  location.reload(); instantly refreshes page when clear cart button is cleared allowing the cart total to show 0E, nextElementSibling grabs the next class right away which would be my faqanswer. 


## User Testing
